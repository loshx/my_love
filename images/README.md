# Imaginile poveștii

Pune aici screenshoturile și pisicuțele. Numele pregătite în pagină sunt:

- `chat-13-martie.png` — primele mesaje, fără inimioare.
- `pisici-28-aprilie.png` — imaginea cu pisici pentru începutul întâlnirilor.
- `chat-28-septembrie.png` — conversația cu inimioare.

Poți folosi și alte nume sau formate; actualizăm căile în `public/index.html` când le adaugi. Fișierele folosite de site trebuie copiate și în `public/images/`, directorul publicat pe Vercel. Originalele rămân aici.

Până adaugi imaginile, pagina arată spații decorative, fără mesaje inventate. Screenshoturile se afișează integral, la proporțiile originale.
